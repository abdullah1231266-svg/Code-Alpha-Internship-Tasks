Network Sniffer - CodeAlpha Task 1

## Description

A Python-based network packet sniffer using Scapy that captures live network traffic and displays:

- Source & Destination IP addresses

- TCP/UDP/ICMP protocols

- Port numbers

- Real-time statistics

## Requirements

- Python 3.x

- Scapy library

## Installation

pip install scapy


Usage

python network_sniffer.py
